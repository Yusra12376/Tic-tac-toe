# Tic Tac Toe

A simple two-player Tic Tac Toe game built with HTML, CSS, and JavaScript. Players take turns placing **X** and **O** on a 3 × 3 board.

## Play the game

1. Download or clone this repository.
2. Open `index Tic.html` in a web browser, or open the project folder in Visual Studio Code and launch `index Tic.html` with the Live Server extension.
3. Click an empty square to place your mark. The game announces a winner when a player completes a row, column, or diagonal.
4. Choose **Reset Game** or **New Game** to start again.

No installation or build step is required. The game runs in the browser.

## Project files

- `index Tic.html` — game board and buttons
- `tak.CSS` — game styling
- `toe.js` — turn handling, win checking, and game reset logic
